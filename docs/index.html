安装教程

如何安装汉化包

1

下载并安装官方 Cheat Engine 7.7

前往 Cheat Engine 官网下载对应平台的安装包并完成安装。

2

下载汉化语言包

从本项目 GitHub Release 页面下载 zh_CN.zip 并解压。

3

放入 languages 目录

将解压出的 zh_CN 文件夹整体复制到 Cheat Engine 安装目录下的 languages 文件夹中。

4

启动并切换语言

默认会跟随系统语言自动显示中文；也可通过命令行参数 CheatEngine.exe --LANG zh_CN 强制指定。

常见问题

FAQ

这份汉化是官方汉化吗？

不是。本项目是社区个人维护的非官方汉化，与 Cheat Engine 官方及其 Patreon 计划无隶属关系。

为什么覆盖率不是 100%？

部分字符串涉及底层技术术语或动态拼接内容，暂未翻译或保留英文以避免歧义，我们会持续补全。

支持哪些操作系统？

汉化包本身是纯文本语言文件，跟随 Cheat Engine 官方支持的 Windows、Linux、macOS 平台使用。

发现翻译错误怎么反馈？

欢迎在 GitHub Issues 提交反馈，或直接提交 Pull Request 参与翻译。

可以在其他版本的 Cheat Engine 上使用吗？

本包主要适配 7.7 版本，低版本可能存在字符串不匹配的情况，建议使用对应版本的语言包。
